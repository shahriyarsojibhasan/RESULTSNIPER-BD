## 📖 পরিচিতি (Overview)

রেজাল্ট প্রকাশের দিনে (বেলা ১১টার দিকে) যখন কোটি কোটি পরীক্ষার্থী ও অভিভাবকদের ট্রাফিকের কারণে সাধারণ সরকারি রেজাল্ট সার্ভারসমূহ ক্র্যাশ বা স্লো হয়ে যায়, তখন কোনো প্রকার ভোগান্তি ছাড়াই দ্রুততম সময়ে ফলাফল, বিষয়ভিত্তিক নম্বর ও মেরিট পজিশন বের করার উদ্দেশ্যে **ResultSniper BD** তৈরি করা হয়েছে।

প্ল্যাটফর্মটি ডেভেলপ করেছেন **শাহরিয়ার সজীব হাসান (Shahriyar Sojib Hasan)**।

## ✨ মূল বৈশিষ্ঠ্যসমূহ (Key Features)

### 1. ⚡ ৩-ইঞ্জিন মাল্টি-গেটওয়ে আর্কিটেকচার (Triple-Engine Architecture)
- **Engine 1: `ebr.bd` (Default Merit Engine)**
  - কোনো ক্যাপচা কোড টাইপ করা ছাড়াই মুহূর্তের মধ্যে রেজাল্ট ও মেধা তালিকা (Merit Position) বের করার ফিচার।
- **Engine 2: `eduboardresults.gov.bd` (Detailed Marksheet)**
  - শিক্ষা বোর্ডের অভ্যন্তরীণ rescrutiny এপিআই ব্যবহার করে প্রতিটি বিষয়ের প্রাপ্ত মোট নম্বর ও বিষয়ভিত্তিক গ্রেড সরাসরি প্রদর্শন।
- **Engine 3: `eboardresults.com` (Multi-Board Nixtec Engine)**
  - ৪-ডিজিট সিকিউরিটি কি সহ সারা দেশের সকল সাধারণ ও কারিগরি বোর্ডের ফলাফল বিশ্লেষণ।

### 2. 🛡️ ব্যাংকনোট-গ্রেড সিকিউরিটি মার্কশিট (Currency-Grade Marksheet)
- **কারেন্সি সিকিউরিটি প্যাটার্ন (Guilloche Waves):** জাল কপি প্রতিরোধে টাকার নোটের মতো গিলোশ অ্যালগরিদমিক কার্ভস।
- **মাইক্রোটেক্সট বর্ডার (Microtext Security Border):** মার্কশিটের চারপাশের বর্ডারে অত্যন্ত সূক্ষ্ম মাইক্রোটেক্সট (`RESULTSNIPER BD • DOC_ID • ROLL ...`) যা প্রিন্ট করলে নিখুঁত সিকিউরিটি দেয়।
- **ইউনিক রোজেট আর্ট (Security Rosettes):** চার কোণায় জ্যামিতিক অ্যান্টি-ফোরজারি রোজেট সিলিন্ডার প্যাটার্ন।
- **বোর্ডভিত্তিক ডায়নামিক ওয়াটারমার্ক (Dynamic Board Watermark):** নির্বাচিত শিক্ষা বোর্ডের লোগো স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে জলছাপ হিসেবে ভেসে ওঠে।
- **অফিশিয়াল হাই-রেজুলেশন লোগো:** রাজশাহী শিক্ষা বোর্ডের অফিশিয়াল ক্রেস্ট সহ ঢাকা, কুমিল্লা, চট্টগ্রাম, যশোর, বরিশাল, সিলেট, দিনাজপুর, ময়মনসিংহ, কারিগরি ও মাদ্রাসা বোর্ডের অফিশিয়াল ভেক্টর/পিএনজি লোগো সংযুক্ত।

### 3. 🔐 কিউআর কোড ও HMAC-SHA256 ডিজিটাল ভেরিফিকেশন (Cryptographic Verification)
- প্রতিটি মার্কশিটের সাথে একটি ইউনিক ক্রিপ্টোগ্রাফিক ডকুমেন্ট আইডি (`RS-XXXXXXXXXX`) এবং HMAC-SHA256 সিগনেচার সংযুক্ত থাকে।
- মার্কশিটে থাকা কিউআর কোড মোবাইলে স্ক্যান করলেই তাৎক্ষণিক `/verify?t=...` পেজে নিয়ে যায় এবং মূল ডেটা অথেন্টিক কিনা তা গ্রিন শিল্ড ব্যানার সহ প্রদর্শন করে।
- কেউ কোনো নম্বর বা গ্রেড ম্যানুয়ালি পরিবর্তন (tamper) করলে তাৎক্ষণিক লাল "INVALID / TAMPERED" সতর্কবার্তা দেখায়।

### 4. 📊 মেধা স্কোর ও বিশ্লেষণ (Merit Score Calculation)
- সর্বমোট কত নম্বর পেয়েছে, ৪র্থ বিষয় ছাড়া আবশ্যিক ও ঐচ্ছিক বিষয়সমূহে মোট নম্বর, এবং সার্বিক অর্জিত পারসেন্টাইল স্বয়ংক্রিয়ভাবে গণনা করা হয়।

### 5. 🤖 অটো-স্নাইপার মোড (Auto-Sniper Mode)
- রেজাল্ট প্রকাশের পূর্বে রোল-রেজিস্ট্রেশন দিয়ে স্নাইপার অ্যাক্টিভ করে রাখলে সার্ভারে রেজাল্ট আপলোড হওয়া মাত্রই অডিও এলার্ট ও কনফেটি সহ রেজাল্ট নিয়ে আসে।

### 6. 📁 ড্র্যাগ-অ্যান্ড-ড্রপ পিডিএফ স্ক্যানার (PDF Rapid Extractor)
- প্রতিষ্ঠানভিত্তিক রেজাল্ট শিট (EIIN PDF) আপলোড করে ০.০১ সেকেন্ডে যেকোনো প্রার্থীর ফলাফল ও স্ট্যাটাস খুঁজে বের করা যায়।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Backend:** Python 3.12, Asyncio, Aiohttp, Cryptographic HMAC-SHA256, Zlib compression
- **Frontend:** Vanilla JavaScript, Modern Tailwind CSS, Custom SVG Guilloche & Rosette Generators, Canvas QR Engine
- **Assets:** Official Education Board Logos (Dhaka, Rajshahi, Chittagong, Comilla, Barisal, Sylhet, Jessore, Dinajpur, Mymensingh, Madrasah, Technical, Bangladesh Govt Seal)
- **SEO & Compliance:** `robots.txt`, `sitemap.xml`, `llms.txt`, `site.webmanifest`, Privacy Policy, Terms of Service

## 🚀 ইনস্টলেশন ও রান করার নিয়ম (How to Run)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
pip install -r requirements.txt
# অথবা
pip install aiohttp requests urllib3
```

### ২. সার্ভার রান করুন:
উইন্ডোজে সরাসরি `start_app.bat` ফাইলে ডাবল ক্লিক করুন, অথবা টার্মিনালে চালান:
```bash
python server.py
```

### ৩. ব্রাউজারে প্রবেশ করুন:
👉 **http://localhost:8080**

## 🌐 এপিআই ও রাউটসমূহ (Routes & Endpoints)

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | মূল ইউজার ইন্টারফেস |

| `GET` | `/api/verify?t={token}` | ভেরিফিকেশন ব্যাকএন্ড এপিআই (JSON) |
| `POST` | `/api/check` | রেজাল্ট সার্চ গেটওয়ে (eduboard/eboard) |
| `GET` | `/about` | সিস্টেম পরিচিতি ও ডেভেলপার বায়ো |
| `GET` | `/terms` | ব্যবহারের শর্তাবলী |
| `GET` | `/privacy` | ডেটা গোপনীয়তা নীতি |
| `GET` | `/llms.txt` | এআই ও এলএলএম কনটেক্সট স্পেসিফিকেশন |
